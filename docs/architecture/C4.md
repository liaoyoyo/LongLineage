# C4 Architecture

## Level 1 — System context

```text
Raw BAM + PASS VCF + latest HP/PS sidecar + FASTA
                         |
                         v
              LongLineage production C++
                         |
                         v
        VALIDATED_FROZEN native artifacts
              |                       |
              v                       v
      posthoc C++ evaluate       read-only presentation
```

Truth can enter only the posthoc evaluator after freeze.

## Level 2 — Containers

```text
longlineage
  preflight -> manifest/schema/hash/index/truth-isolation
  run       -> block reader -> M1 -> M2/co-occurrence -> topology -> writer
  probe     -> bounded diagnostics with mandatory PARTIAL status

longlineage-validate
  independent record/count/digest/conservation validation

longlineage-export-legacy
  native record transformation only

longlineage-evaluate
  truth-aware posthoc benchmark of VALIDATED_FROZEN runs

longlineage-query
  validated-only read-only record lookup
```

## Level 3 — Components

- `schema`: typed fields, enum vocabulary and catalog.
- `io`: HTSlib handles, CIGAR projection, MM/ML, VCF and sidecar exact join.
- `runtime`: byte-bounded queues, thread pool, reorder buffer and run state.
- `m1`: deterministic methylation partitioning.
- `m2`: eligibility, exact association, co-occurrence and multiplicity.
- `solver`: exact objective, family enumeration and parent mapping.
- `artifact`: BGZF writer, canonical semantic digest and receipts.
- `validator`: independent readers and conservation rules.

## Error propagation

Any parser/worker/writer error cancels dispatch, joins threads and records FAILED.
Only the independent validator may authorize atomic freeze.
