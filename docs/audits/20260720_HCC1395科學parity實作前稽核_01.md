# HCC1395 科學 parity 實作前稽核

> **Task B / FULL HCC1395 DATASET GATE / PROBE**
> 這份稽核允許實作與 bounded probe，不允許把尚未通過獨立 replay 的結果稱為
> production、完整 parity 或七資料集 release。

## 0. Cynefin front gate

- 分類：**Complex**。
- 判斷理由：typed I/O 與 P2 synthetic block pipeline 可預測，但 P3/P4 尚無 C++
  科學 kernel，P4 沒有成功的歷史 full authority，P5 hard cases 的 family/ranking
  仍不完整。
- 行動：probe-first。先凍結小型 oracle 與 falsifier，再逐 phase 實作；禁止直接
  啟動 HCC1395 全基因組長跑。

### Falsifier observable

任一情況發生即停止升級：

1. frozen fixture 的 key、status、K、partition、FDR family 或 semantic digest 有一筆
   不一致；
2. sidecar exact identity 出現 missing、extra、multimatch 或 conflicting tag；
3. q>4 family 在 cap/deadline 前不完整，卻產生 rank/winner；
4. independent validator 無法從 artifact 重算 conservation/digest，或 producer 與
   validator 共用科學 kernel；
5. 24/40 workers 的 semantic SHA 不一致；
6. HCC gate 被誤標為七資料集 production release。

## 3. Assumption map

### 高重要、已知

- production 不讀 truth；truth 只可在 frozen run 後的 evaluation domain。
- BAM 本身無 authoritative HP/PS；只能使用 frozen sidecar exact projection。
- O/X 不可合併成 R，unknown enum/duplicate/out-of-order 一律 fail closed。

### 高重要、未知，必須先驗

- PCG64、距離、linkage tie、relabel 與 HP-family mapping 能否 byte/decision parity。
- Endpoint-B O/X callability precedence 與 K×2 exact-test vectors是否完整。
- q>4 HCC units 的完整 family 是否可在資源限額內完成。
- independent validator 是否能不連結 producer kernel 而重播所有 conservation。
- full run 在 NFS raw BAM 下的 wall/RSS/I/O 與 24/40-worker determinism。

### 低重要、已知

- readiness HTML 可以離線重生；它不是科學 evidence。

### 低重要、未知，可延後

- 公開 release 與跨平台 package；本輪維持 private。

## 4. Probe 路徑與 checkpoint

1. 凍結 P3/P4/P5 小型正負 vectors。
   - Checkpoint：schema/digest 全有、truth field=0、來源與方法相容性清楚。
2. 實作單 phase producer + 獨立 oracle，依序 P3 → P4 → P5。
   - Checkpoint：每 phase 零 discrete mismatch；不符合就停在該 phase。
3. 實作 staging → validator → atomic freeze，加入故障注入。
   - Checkpoint：所有 forged/missing/extra/modified artifact 均非零退出。
4. 執行 bounded real HCC window，但結果標 `PARTIAL`，不可成 release evidence。
   - Checkpoint：exact join conservation=0 mismatch、1/4 worker digest相同。
5. 只有上述全綠才跑 HCC whole genome 24/40 worker。
   - Checkpoint：兩次 semantic SHA 相同且狀態為
     `VALIDATED_FROZEN_DATASET_GATE`；`production_claim_allowed=false`。

## 7. Verdict 與 red team

### Verdict

**PROBE（50/100）**。允許開始受控實作與小型 parity probe；不允許直接啟動
HCC1395 全基因組或宣告 production。

### Red-team failure modes

1. **假 parity**：只比 aggregate counts，忽略 read/site keys、reason codes、O/X、
   RNG 與 tie ordering。
2. **方法偷換**：拿失敗或 truth/CN boundary 不同的舊 co-occurrence/tree 輸出作
   exact golden。
3. **拓撲過度主張**：objective certified 被誤寫成 family/ranking complete，或以
   VAF 選 parent edge。
4. **validator 非獨立**：producer 與 validator 共用同一 statistical/solver kernel，
   同一 bug 會同時通過。
5. **效能假改善**：bounded/synthetic speedup 被外推到 292 GB NFS BAM。

### Decision lock

- 只有完成 probe checkpoints 才能把 verdict 升為 GO full HCC run。
- 任何 cap/deadline/incomplete family 均保持 abstain，不能用近似 winner 補洞。
- HCC dataset gate 通過仍不等於七資料集 P7/P8 release。
