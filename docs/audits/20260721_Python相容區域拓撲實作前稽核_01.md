### Falsifier observable

以下任一項成立即停止 full run／速度宣稱：

1. 任何 region key、densest-8 selected loci、HP family或≥3-read pattern不一致；
2. sidecar missing/conflict/multimatch或BAM舊HP fallback非零；
3. workers=1與workers=24 semantic SHA不同；
4. legacy cap/incomplete unit卻被C++標為complete/determined；
5. truth/CN path進入L0/L1 producer selection；
6. Python與C++時間不是同樣本、同scope、同輸出責任卻被寫成speedup。

## 3. Assumption map

### 高重要、已知

- region由同染色體排序site的**相鄰 gap <= 50,000 bp**傳遞閉包形成；總span不設上限。
- >8 loci取span最小的第一個連續8-locus window；minimum-support為每一完整／部分pattern 3 reads。
- HP `1/1-1/1-2→1`、`2/2-1/2-2→2`、`3→3`、`4→4`、`.`→`none`。
- output只可稱regional mutation-state family；不是clone、ancestor或time order。

### 高重要、未知，必先驗

- HTSlib flag filter是否逐read重現pysam `stepper=samtools`，尤其supplementary與QCFAIL。
- CIGAR投影對OTHER/deletion/refskip/missing-base是否完全重現R/A/X。
- legacy cap fallback與Python set iteration是否改變capped unit的非決策欄位。
- 同一raw BAM在bip7/big7/big8名稱混用時，實體inode/mount與authority是否相同。

### 低重要、可延後

- CN/LOH L2 exact annotation parity；production-compatible mode固定`unavailable`。
- Python nested JSON byte-for-byte parity；本任務使用排序後typed semantic rows作權威。

## 4. Step → Verify gates

1. Port grouping/pattern/legacy solver並建立負例。
   → 驗證：golden cases、tie/cap/HP vocabulary、workers 1/4 semantic SHA exact。
2. 對 frozen mlhp 五片做C++ solver replay。
   → 驗證：20,119 units及每unit class/n_hidden/n_trees零差異。
3. 對小型real region做BAM differential。
   → 驗證：alignment exposure、HP、R/A/X pattern逐鍵零差異。
4. 全HCC workers=24；必要時workers=1只重播同一已凍結pattern artifact以量solver scaling，
   不重複292 GB BAM I/O冒充有必要的驗證。
   → 驗證：8,222 regions、20,119 units、10,904 primary units與class census exact。
5. 獨立validator後atomic freeze。
   → 驗證：corrupt/missing/extra/modified artifact均非零退出；valid bundle PASS。

## 7. Verdict 與 red team

**PROBE-first，通過後自動升GO full HCC。**

最強反方：

1. aggregate 8,222可能只證明VCF grouping，掩蓋read/HP/unit全面不一致；所以驗收必須逐鍵。
2. 速度可能來自少輸出、跳過V1–V7或不讀BAM；所以比較需列同scope責任與stage時間。
3. 使用帶truth的persisted tagged BAM可意外重現舊數字；所以正式相容run只能用raw BAM＋
   truth-free sidecar，tagged BAM只可隔離對照。

不得因有非零region而宣稱clone/ancestor/temporal lineage。
