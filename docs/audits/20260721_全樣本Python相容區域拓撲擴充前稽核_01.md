# 全樣本 Python-compatible regional topology 擴充前稽核

> **Task B / FULL 7 DATASETS / PROBE-FIRST**
> 本任務服務 LL-G1、LL-G2、LL-G4、LL-G5。目標是把已在 HCC1395 驗證的
> `PYTHON_V2_DESCRIPTIVE_REGIONAL` C++ endpoint，以相同科學契約執行於完整權威七 dataset；
> 不修改 formal M2 membership，也不把描述性 region 稱為 clone、ancestor 或時間順序。

## 0. 30 秒結論

拓撲演算法可直接泛化，因 grouping、HP family、MINREAD 與 solver 都沒有 sample 特例。
但正式全量 run 前有兩項 P0：第一，producer/validator 必須補齊 dataset 與 input authority 的
fail-closed 驗證；第二，除 HCC1395 外的六個 raw BAM 尚無 full-content SHA-256，不能把 sampled
storage identity 冒充檔案 digest。完成這兩項後才可由 PROBE 升為 GO。

## 2. 固定 research template

- **Research question**：同一個 Python-v2 描述性區域契約能否在七個權威 dataset 上，以
  C++/HTSlib deterministic parallel pipeline 產出與 frozen Python descriptive fields 逐鍵一致的結果？
- **Hypothesis**：移除 I/O 層的 HCC label 特例後，科學 kernel 無須修改；相同輸入角色與固定參數
  應得到逐 dataset 的 region/unit/pattern exact parity，workers 不改變內容。
- **Success**：七個 dataset 各自通過 full SHA input lock、producer、獨立 validator、`FROZEN`，且
  與 frozen Python MLHP/region view 的 descriptive keys mismatch=0；cohort 報告守恆。
- **Failure**：任一 dataset authority、role、SHA、前後 identity、TSV invariant、Python crosswalk 或
  w1/w24 bounded determinism不通過；任一失敗均不得被總表掩蓋。
- **Primary metrics**：regions、units、patterns、primary units、unit class census、region determinacy、
  exact mismatch counts、wall/preflight/science/validator seconds、RSS、workers。
- **Inputs/limits**：raw untagged BAM + BAI、LongPhase-S recalibrated `FILTER=PASS` VCF + CSI、
  truth-free latest HP/PS sidecar + TBI、GRCh38 + FAI；chr1-22；不得使用 truth VCF/BED 或 persisted tagged BAM。
- **Expected output**：七個獨立 closed frozen bundle、七個 C++ crosswalk receipts、cohort receipt、HTML。

## 4. 實作前 trust-boundary 稽核

### 4.1 可保留不變

- `regional_topology.cpp/.hpp` 零 `HCC1395`/dataset/profile 特例。
- adjacent gap `<=50,000` 的 transitive grouping。
- >8 sites 的 first-tie densest consecutive 8。
- HP prefix family `1/2/3/4/none`、MAPQ 20、BASEQ 0、MINREAD 3。
- CPython 3.9 capped fallback 與 legacy enumeration；capped 仍是 abstain。

### 4.2 P0 缺口

1. producer 目前只接受 HCC manifest，且 `load_variant_sites()` dataset/order 寫死。
2. producer 目前只做 size/mtime snapshot，沒有呼叫 `verify_locked_file()` 重播 manifest SHA。
3. producer 沒有驗證 production/HCC input authority binding。
4. summary/producer/validation receipt 沒有強制 dataset ID/order/profile binding。
5. validator positive fixture 即使缺 `inputs`、`parameters`、`timing` 仍可 freeze；與 closed schema 不一致。

這些是 provenance/validator 問題，不推翻已完成的 HCC scientific parity，但若原樣複製到七樣本，
會讓 bundle swap 或自行宣告 digest 無法 fail closed。

## 5. Step → Verify

1. 泛化 dataset selection 並重播 repository authority。
   → 驗證：完整 `PRODUCTION_7_DATASET` set/order、唯一 `--dataset-id`、八角色與 authority SHA；
   missing/reorder/unknown/wrong binding 全部非零退出。
2. selected dataset 八檔 full SHA preflight，再做便宜的前後 inode/device/size/mtime/ctime TOCTOU。
   → 驗證：每個 role 記錄 `PHYSICAL_SHA256_VERIFIED`；任一 digest/identity 變化即無 output freeze。
3. 將 dataset、authority、claim ceiling 納入 compat schema v2、semantic digest 與三層 receipt。
   → 驗證：交換 dataset ID、缺 inputs/parameters/timing、duplicate role、unknown field 均被獨立 validator 拒絕。
4. 先跑 synthetic/CTest/HCC regression/小樣本 bounded probe。
   → 驗證：HCC 三份 science TSV 不變；同 dataset w1/w24 probe byte-identical。
5. 建立六個缺少的 raw BAM full SHA authority，依 dataset order 逐一跑 24 workers。
   → 驗證：七個 output root 各有 validator receipt 與 SHA-bound `FROZEN`；任何一個 fail 就停止 cohort freeze。
6. 用 C++ crosswalk frozen Python descriptive fields；Python 只讀 validated chart-ready receipt 產 HTML。
   → 驗證：region/unit/pattern/solver mismatch=0，報告 aggregate/canonical/extreme/well-explained 四層可追溯。

## 6. 資源與排程 gate

盤點主機為 24 physical/48 logical CPU，RAM available 約 489 GiB；`<BIG8_INPUT_ROOT>` 是 NFS 4.2。
HCC w24 的 summed input/solver 為 6,979.66/28.78 秒，solver 僅 0.41%，主要瓶頸是 BAM/NFS。
樣本內使用 24 workers、樣本間循序；兩個 w24 會超過 48 logical threads 並爭搶 NFS。

2026-07-21 11:18 的 load 為 76，超過 policy planning ceiling 60，且有其他 session 的 D-state
廣域搜尋。此狀態下不得啟動 science 或把 contention wall 當正常 benchmark。idle science 規劃約
35–75 分鐘；六個 BAM 首次 full SHA 建立時間另計，預期才是本次最長 preflight。

## 7. Falsifiers 與停止條件

1. truth-bearing key/path/value、persisted tagged BAM 或 embedded BAM HP fallback 進 producer。
2. 六份 sampled identity 被標成 full SHA。
3. full manifest dataset set/order與 frozen authority不同。
4. 任一 selected input full SHA 或前後 identity不一致。
5. HCC regression science TSV改變；代表泛化污染 kernel。
6. 任一 Python descriptive crosswalk mismatch非零。
7. validator仍能接受缺 dataset/inputs/parameters/timing 或重新封裝的 bundle swap。
8. 在 load >60 或有本 session NFS conflict 時啟動全量，卻宣稱是受控 speedup。

## 8. Verdict

**PROBE（程式與 authority 建立可進行；science launch 暫不可 GO）。**

升級為 GO 的必要條件：compat v2 trust gap 測試全過、HCC regression不變、七 dataset manifest
都有真實 full-content SHA、主機/NFS resource gate通過。滿足後依固定 order自動進入完整 run；
不需以 subset 取代 Task-B 驗收。
